STEP 2 — DRIVER ONLINE / OFFLINE SYSTEM

If the system exists:
Improve UI only if needed.

If missing:
Implement a driver availability toggle.

Requirements:

Driver Dashboard should contain:

Driver Status
[ GO ONLINE ] / [ GO OFFLINE ]

When GO ONLINE:
Driver becomes available for ride requests.

When GO OFFLINE:
Driver receives no ride requests.

Store driver status in database:

driver_status = online | offline

Update backend listener so only ONLINE drivers receive trip requests.

If this system is missing, implement it.

When a rider requests a trip:

Show a popup card on the driver screen:

New Ride Request

Pickup: {pickup_location}
Dropoff: {dropoff_location}

Distance: {distance}
Fare Estimate: {estimated_fare}

Buttons:
ACCEPT
DECLINE

Driver has 10 seconds to respond.

If ACCEPT:
